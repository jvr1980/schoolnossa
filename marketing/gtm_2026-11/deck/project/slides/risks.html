What could go wrong, and what happens then. If your Mac is off on Monday, the queue still covers two weeks, and the ad rules run in the cloud. If Meta rejects an ad, the next variant goes in. If the access key stops working, you get a failure email the same morning, and the caps still hold. A wrong date can't get through, because the fact check blocks it. Reach will start small, which is why the ads and YouTube search carry the first months. And because YouTube locks uploads from new API projects, I upload through YouTube Studio in Chrome until the audit passes.
